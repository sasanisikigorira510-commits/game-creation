# Project Instructions

- New game art and visual materials must be generated with ChatGPT image2 and the generated image2 files must be used in the game. This includes UI icons, buttons, backgrounds, effects, particles, characters, sprites, textures, cutscene art, and other visual assets.
- Do not substitute existing project assets, stock assets, assets from other generators, or locally drawn placeholder art when a new visual asset is needed, unless the user explicitly approves that specific substitution.
- When the user asks to "囲って" or highlight something with a "枠", prefer the previously generated image2 frame asset; if they explicitly ask for a yellow frame, use a clear yellow frame.
- Do not replace requested asset generation with purely local procedural drawing or recoloring unless the user explicitly asks for that fallback.
- Local scripts may be used only for post-processing image2 outputs, such as cropping, resizing, transparency cleanup, metadata/meta files, and Unity import preparation.
- If image2 is unavailable, fails, or produces unusable output, report that clearly and ask before using a non-image2 fallback.
