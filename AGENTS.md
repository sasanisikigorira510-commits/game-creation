# Project Instructions

- Game art/material generation must use image2/image generation first. This includes UI icons, buttons, backgrounds, effects, sprites, textures, and other visual assets.
- Do not replace requested asset generation with purely local procedural drawing or recoloring unless the user explicitly asks for that fallback.
- Local scripts may be used only for post-processing image2 outputs, such as cropping, resizing, transparency cleanup, metadata/meta files, and Unity import preparation.
- If image2 is unavailable, fails, or produces unusable output, report that clearly and ask before using a non-image2 fallback.
